## Phạm vi dự kiến

Tích hợp backend, quản lý phiên và xử lý dữ liệu mạng. Nội dung sẽ đi từ khái niệm đến thực hành, tập trung vào cách tiếp cận Angular hiện đại.

## Các bài trong nhóm

- **[HttpClient](/docs/http-api-auth/http-client)** — Gửi request, ánh xạ response và cấu hình tùy chọn HTTP.
- **[Interceptors](/docs/http-api-auth/interceptors)** — Can thiệp request/response cho auth, logging và metadata.
- **[Xử lý lỗi API](/docs/http-api-auth/xu-ly-loi-api)** — Chuẩn hóa lỗi, retry có kiểm soát và phản hồi trên giao diện.
- **[Authentication](/docs/http-api-auth/authentication)** — Thiết kế luồng đăng nhập, token và bảo vệ phiên người dùng.
- **[Cache dữ liệu](/docs/http-api-auth/cache-du-lieu)** — Giảm request lặp lại và quản lý tính mới của dữ liệu.
- **[Realtime](/docs/http-api-auth/realtime)** — Tích hợp WebSocket hoặc Server-Sent Events với Angular.
